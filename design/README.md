# 個人網頁改版設計稿

`redesign-2026.svg` 是 [longtai.org](https://longtai.org) 的新版設計稿，整張畫布用純 SVG 向量繪製，
沒有外部圖片或字型依賴，直接用瀏覽器開啟即可，也可以匯入 Figma / Illustrator 再修改。

## 畫布內容

| Artboard | 尺寸 | 說明 |
| :--- | :--- | :--- |
| DESKTOP | 1440 × 5723 | 桌機版全頁，從導覽列到頁尾 |
| MOBILE | 390 × 1801 | 手機版，含首屏、數據、關於我、經驗與頁尾 |
| TOKENS | 640 | 色票、字級、圓角、間距與元件樣式 |

## 設計方向

延續現有的深色藍識別（`#1b212c` 底色、`#00a8f0` 主色），主要調整版面與層次：

- **首屏**：左文右圖的雙欄結構取代置中排版，加上軌道線與光暈呼應衛星軌道設計競賽。
- **數據列**：把 18 筆經歷、31 張證書、4 張 Google 專業證書、21K 完賽距離拉到首屏下方。
- **經驗與活動**：2026 年的三個重點做成精選卡，其餘 15 筆改成年份分組的年表，比原本的等寬卡片牆更好掃讀。
- **證書**：新增獨立區塊，四張 Google 專業證書直接露出，其餘 27 張收在展開列。
- **區塊標題**：統一為「編號 — 英文標籤 + 中文大標」，右側放計數或連結。
- **卡片**：左上角 56 × 3px 主色標籤條取代整條頂線，圓角一致收斂成 16 / 18 / 20 / 24。

向量頭像是佔位圖，實際會放 Gravatar 上的照片。

## 重新產生

設計稿由 `scripts/generate_design_svg.py` 產生，資料直接讀 `public/json/*.json`，
所以經歷、證書、文章、友站一有更新，重跑就會同步：

```bash
python3 scripts/generate_design_svg.py
```
